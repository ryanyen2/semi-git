## Explore your feature tree

The **ugh** activity bar container shows your codebase clustered into features, straight
from `ugh map`. Edit and run `ugh save -m "..."` from a terminal as you normally would — the
tree, gutter blame, and changes view here all refresh from the same store.

<button data-command="workbench.view.extension.ugh">Open the ugh view</button>
