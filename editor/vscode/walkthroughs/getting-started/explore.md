## Explore your feature tree

The **semi-git** activity bar container shows your codebase clustered into features, straight
from `sgt map`. Edit and run `sgt save -m "..."` from a terminal as you normally would — the
tree, gutter blame, and changes view here all refresh from the same store.

<button data-command="workbench.view.extension.semi-git">Open the semi-git view</button>
