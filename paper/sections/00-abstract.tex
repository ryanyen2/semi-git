\begin{abstract}
A developer working through a coding agent specifies intent in sentences but
version control records lines in commits. The developer who wants to undo one
request must recover which functions it produced, a decomposition they stated
before any code existed and nothing wrote down.

We present \sgt{}, which records one edit per changed function, groups edits into
named features by how they change together, and rebuilds files from whichever set
is included. A version is a set of edits; removing a feature is set difference;
restoring it is set union. The record lives inside an ordinary git repository and
requires no server.

A pilot study found the split the evaluation predicts: a new user adopted the
comprehension layer on first contact (attribution, dependency display, revert
preview) and declined the write layer after one session, because three of four
mutation commands failed. The comprehension layer told the developer what to
change; the write layer could not yet be trusted to change it. We report both
halves, state which measures would count against the design, and pre-register the
study that would produce them.
\end{abstract}
