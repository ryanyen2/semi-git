\opsrow{\thsave}{sgt save -m "..."}
  {One record per changed function, filed under a name for the request.}
  {The grouping is a guess. When it is wrong the developer moves labels, and no
   recorded edit changes.}
\opsrow{\thwhy}{sgt show api.py::handle}
  {The request this function came from, the saves that touched it, and how many
   edits removing it would take along.}
  {The answer is exactly as good as the grouping behind it.}
\opsrow{\threvert}{sgt revert "price cache"}
  {The named set subtracted from the version, with every function it changes
   named before anything is applied.}
  {A function later work also edited has the set's lines subtracted from its
   current text, and the developer's tests decide whether the result stands.}
\opsrow{\threstore}{sgt restore "price cache"}
  {The same set back, byte for byte, with everything added since left alone.}
  {Refused when putting it back would leave two versions of one function live,
   and the refusal prints edit identifiers with no function name attached.}
\opsrow{\thdiff}{sgt diff main feat/export}
  {The edits each version has that the other does not, in both directions.}
  {It answers in functions, so seeing which lines moved still means opening the
   file.}
\opsrow{\thswitch}{sgt switch feat/export}
  {The working files rebuilt from that branch's set.}
  {Refused on unsaved edits, because \sgt{} has nowhere to put them yet.}
\opsrow{\thckpt}{sgt intent list}
  {Each feature cut into the stretches of work done on it, each with a name like
   \cmd{rate limiting@2} that the other commands accept.}
  {The cuts come from a language model reading the saves, so a stretch can start
   one save too early.}
\opsrow{\thfork}{sgt resolve api.py::handle}
  {The two competing versions of the function side by side, and whichever one the
   developer picks or writes is included once the project's test command passes.}
  {Two edits at opposite ends of one function are also competing versions, and
   git would have merged them without asking.}
\opsrow{\thplan}{sgt plan intake "..."}
  {A name for work that does not exist yet, which the next save matches itself
   against.}
  {A plan that predicts whole files matches nothing. It has to name functions.}
\opsrow{\thsubset}{sgt propose land --subset "export"}
  {One finished feature sent to the shared branch, with the unfinished one left
   behind.}
  {Two functions that sit next to each other in one file can lose the blank line
   between them.}
