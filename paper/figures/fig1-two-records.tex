% Figure 1 (teaser). One agent session, recorded two ways.
\newcommand{\FigOneCaption}{One hour of work with a coding agent, and the two
records it leaves behind. The developer asked for three things and got a fourth
(left). Git kept two commits whose fifteen hunks interleave all four requests
(middle). The colours in that panel are ours, and git holds no record of which
request produced which hunk, so a developer taking one request back out has to
decide for each hunk whether it belongs to that
request. \sgt{} recorded one edit per function and filed each under the request it
came from (right), so the caching work is a set of six edits with a name, and the
one function both the rate limiter and the cache touched is visible as such.}

\newcommand{\FigOneDescription}{A three panel diagram. The left panel lists the
three requests a developer made to a coding agent and one change the agent made
without being asked, each in its own colour. The middle panel shows two git
commits drawn as stacks of file names with coloured diff hunks inside them,
where the hunks of every colour are mixed together inside both commits. The
right panel shows four horizontal lines, one per request, with square, circular
and triangular marks placed on each line under the commit in which that edit
happened, plus tick marks for checkpoints and a line joining the two marks that
edited the same function. The bottom row asks the same task of both records:
removing the caching request takes six hunk selections across three files and
two commits under git, and one named command under sgt.}
